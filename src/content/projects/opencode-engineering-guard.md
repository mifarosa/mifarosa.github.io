A global OpenCode plugin that stops coding agents from jumping from the first plausible search result straight into code changes. Agents can investigate, reproduce and run diagnostics freely, but product edits stay locked until an analysis step is recorded, and every change ends with a diff and targeted validation.

Currently at v4, with separate modes for bug fixes and for batch generation of tests and scripts.
