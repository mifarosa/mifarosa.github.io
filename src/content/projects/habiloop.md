A habit tracker for iPhone, desktop and Android that is compatible with Loop Habit Tracker, the open-source Android app. It opens a Loop backup (.db) directly and exports back to the same format, so a habit history can move between Loop and the browser.

Supports yes/no and numerical habits with any frequency, and calculates the same habit strength score as Loop, with a 90-day score chart, streaks and a monthly calendar where any past day can be edited. Data lives in a real SQLite database inside the browser (sql.js), so nothing leaves the device. Works offline and installs on Android and iOS. English and Turkish.
