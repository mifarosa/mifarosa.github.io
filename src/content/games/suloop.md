Pour coloured water between glass tubes until each tube holds a single colour. Tap a tube to pick it up, then tap another to pour. Liquid only goes into an empty tube or onto the same colour.

The levels never run out. They start with three colours and add one every two levels, and a solver checks every level before you see it, so each one can be solved. A daily puzzle is the same for everyone. Undo, restart and hints are there when you get stuck. It is drawn on a plain canvas with no libraries, so it stays light and smooth on phones, and it remembers your level. Turkish interface.
